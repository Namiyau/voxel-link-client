# Voxel Link 纯客户端 v0.6.3

> v0.6.3：LOD 分阶段加载、GPU 上传限速、初始化误降级修复，并修复远山缝隙、取消 R 飞行键，新增地形与光影预设。
## 本地启动

双击 `start-client.bat`，然后访问：

```text
http://127.0.0.1:8080/?v=0.6.3
```

或者：

```powershell
py -m http.server 8080
```

不要直接双击 `index.html`。

## GitHub Pages

将本包全部文件上传到仓库根目录，然后在 `Settings → Pages` 选择 `main / (root)`。

## 联机

纯客户端只负责网页和单机。联机时需连接另行启动的完整版服务端：

```text
wss://你的公网地址/ws
```

本地 8080 静态服务器没有 `/status` 和 `/ws`；v0.6.3 不会再自动把它当作游戏服务器。

## v0.6.3 修复

- 初始只排队最粗 LOD，完成后每隔一个稳定阶段逐级细化。
- Worker 网格先进入待上传队列，每帧限制安装数量和上传字节。
- 待上传队列满时暂停派发，防止瞬时内存和显存峰值。
- 初始化 20 秒内不因普通压力自动降级；排队数量不再作为降级条件。
- 自动视距调整具有持续判定与 20 秒冷却，避免连续重建。
- 飞行时可用 `R` 上升，`Ctrl+R` 高速上升；失焦时清空卡住的按键。
- 保留近景遮罩、方块修改 revision 与原子替换修复。

## v0.6.0 基础修复

- 消除不同 LOD 层的垂直高度差和深度偏移差，修复远景同心暗环。
- 所有 LOD 水面保持完全一致的高度。
- 远景纹理采用固定世界尺度，避免层级切换出现亮度带。
- LOD 边界改为不规则但互补的不透明轮廓，不产生透明混合或地图空洞。
- 保留月亮、E 背包、创造全物品页、时间控制、Shift 下蹲和资源峰值保护。

推荐先使用近景 16、远景 1024、柔和光影。64/2048 仍属于实验极限。
