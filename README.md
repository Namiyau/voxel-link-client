# Voxel Link

简体中文 | [English](README.en.md) | [日本語](README.ja.md)

**浏览器体素沙盒 · Web 实时联机 · 超远四叉树 LOD · 纯零构建单机即跑**

一个为 **AI 生成的游戏预览** 与 **地图世界展示** 打造的 Web 端体素平台：无需安装、无需构建，静态文件拷上即用；程序化生成广袤地形的八类地标，近景完整方块与远景宏体素同屏无缝衔接，并提供 WebSocket 联机能力。

---

## 功能亮点

| 领域 | 能力 |
| --- | --- |
| 渲染 | Three.js 驱动，近景全像素 `16×256×16` 方块网格 + 远景四叉树宏体素 LOD（视距可达 2048 区块） |
| 视觉 | 程序化像素纹理、世界空间水面、自研天空着色器、6 套内置光影预设、分层雾 |
| 地形 | FBM 大陆 + 侵蚀山脊 + 8+ 类地标（火山 / 台地 / 尖峰 / 浮空岛 / 高山 / 峡谷 / 盆地 / 地盾）+ 自然 / 树木 / 水下地形 |
| 性能 | Web Worker 网格构建、缓冲区转移动量化、GPU 上传限速、20 秒初始化包容、持续压力自动降视距并冷却 |
| 单机 | 3 个 localStorage 存档槽，保存种子、位置、时间、库存与玩家修改的方块 |
| 联机 | WebSocket，10Hz 移动同步、方块修改确认回滚、玩家名单/消息/模式、断线自动重连 |
| 稳定性 | WebGL 上下文丢失恢复、安全模式降级渲染、多处 CDN 兜底、引擎本地化 |

## 快速开始

### 本地

```powershell
# 方式 1：需要 Node.js 20+
双击 start-client.bat

# 方式 2：任意静态文件服务器
py -m http.server 8080
```

访问 `http://127.0.0.1:8080/`。**不要直接双击 `index.html`**（ES 模块与 Worker 依赖 http 协议）。

### GitHub Pages

本仓库可静态托管。在 Settings → Pages 选择 `main / (root)` 即可；发布后访问对应的 `namiyau.github.io/voxel-link-client`。

## 联机

客户端只能承载网页与单机。联机需要**另行部署的服务端**，可在 [Releases](../../releases) 下载服务端安装包，部署步骤见 [docs/DEPLOY.zh-CN.md](docs/DEPLOY.zh-CN.md)。

服务端启动并暴露公网后，在菜单填写（请改用你的服务器地址与 `wss`）：

```text
wss://你的公网地址/ws
```

- 服务端提供 `/status`（HTTP 状态查询）与 `/ws`（WebSocket）两个端点。
- 本地静态服务器（8080 端口）不含这两个路由，不会被误当游戏服务器。
- 公网部署建议：VPS + 反向代理（Caddy/nginx + TLS）→ `wss`；开发期可用 FRP/SakuraFrp 内网穿透。
- 断线自动重连（指数退避，最多 5 次），本地进度回退提示，重连后自动恢复。

## 技术架构

```
index.html
├─ src/three-loader.js   Three.js 本地优先，多条 CDN 兜底
├─ src/main.js           应用装配、联机消息、资源守护、UI 事件
├─ src/world.js          全量方块与四叉树 LOD 调度、预算与装卸
├─ src/mesh-worker.js    网格构建 Worker（随硬件并发 1–4 线程）
├─ shared/               与 Worker 共享的纯函数
│  ├─ constants.js       方块 ID、地图参数
│  ├─ worldgen.js        程序化地形生成
│  ├─ lod.js             四叉树 LOD 层级与带宽切割
│  └─ mesh-builders.js   体素/宏体素网格构建
├─ src/visuals.js        光影预设、天空、动态分辨率
├─ src/materials.js      程序化像素纹理、连续水面、LOD 近景遮罩着色器
├─ src/settings.js       本地设置持久化
└─ vendor/               three.module.min.js（本地依赖）
```

核心思路：`shared/` 目录模块在主线程与 Worker 中复用，Worker 返回 TypedArray 网格（transferable）后由主线程限速安装，**旧网格保持显示、新网格就绪后原子替换**，避免流式加载时的裂缝与闪烁。

## 视觉预设

| 预设 | 说明 | 负载 |
| --- | --- | --- |
| 原版像素 | 无投影、无色调映射，性能优先 | 低 |
| 柔和光影 | ACES 色调映射 + 投影，默认推荐 | 中 |

| 极光梦境 / 落日暖辉 / 清晨通透 | 风格化配色 | 中 |

## 存档与设置

- 单机存档：3 槽，保存种子、位置、时间、生命值、背包与全部修改方块（生成器确定性保证未修改区域可随时重建）。
- 设置：视距、光影、名称、游戏模式、灵敏度等自动保存到浏览器 `localStorage`，下次打开直接生效。
