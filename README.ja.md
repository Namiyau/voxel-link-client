# Voxel Link

[简体中文](README.md) | [English](README.en.md) | **日本語**

**ブラウザ体素サンドボックス ・ リアルタイムWebマルチプレイ ・ 超遠距離クアッドツリーLOD ・ ビルド不要ですぐ遊べる**

**AI生成ゲームのプレビュー**と**ワールド展示**のために作られた、Webベースの体素プラットフォームです。インストールもビルドも不要で、静的ファイルをサーバーに置くだけですぐ動きます。プロシージャル生成により広大な地形と8種類以上の絶景（ランドマーク）を生み出し、目の前のフルクオリティ・ブロックと遠景のクアッドツリーLODがシームレスに融合します。マルチプレイはWebSocketで動作します。

---

## 機能のハイライト

| 領域 | 内容 |
| --- | --- |
| 描画 | Three.jsドライブ：近景はフルディテールの `16×256×16` ブロックメッシュ、遠景はクアッドツリーLOD（視界距離は最大2048チャンク） |
| ビジュアル | プロシージャルなピクセルテクスチャ、ワールド座標の水面、自作の空シェーダー、内蔵ライティングプリセット6種、レイヤードフォグ |
| 地形 | FBM大陸＋侵食された稜線＋8種類以上の絶景（火山 / テーブル台地 / 尖塔 / 浮遊島 / 高峰 / 峡谷 / 盆地 / 楯状地）+ 自然 / 森林 / 水中地形 |
| パフォーマンス | Web Workerによるメッシュ構築、バッファ転送の量子化、GPUアップロードのレート制限、初期化後20秒の猶予、高負荷時に視界距離を自動で下げるクールダウン |
| シングルプレイ | localStorageに3スロットのセーブ。シード・位置・時刻・体力・インベントリ・編集した全ブロックを保存 |
| マルチプレイ | WebSocket、10Hzの移動同期、承認制ブロック編集（ロールバック対応）、プレイヤーリスト / チャット / モード、自動再接続 |
| 安定性 | WebGLコンテキスト喪失からの復旧、セーフモードによる描画フォールバック、複数のCDNフォールバック、エンジンのローカル化 |

## クイックスタート

### ローカル

```powershell
# 方法 1：Node.js 20以降が必要
start-client.bat をダブルクリック

# 方法 2：何らかの静的ファイルサーバー
py -m http.server 8080
```

ブラウザで `http://127.0.0.1:8080/` を開いてください。**`index.html` を直接ダブルクリックしないでください**（ESモジュールとWorkerは http 由来が必要です）。

### オンラインでプレイ

GitHub Pages にデプロイ済み：[namiyau.github.io/voxel-link-client](https://namiyau.github.io/voxel-link-client/)

## マルチプレイ

クライアントが提供するのはWebページとシングルプレイのみです。マルチプレイには**別途デプロイするサーバー**が必要です。[Releases](../../releases) からサーバーパッケージをダウンロードし、[docs/DEPLOY.ja.md](docs/DEPLOY.ja.md) に従って構築してください。

サーバーを起動して公開したら、メニューでアドレスを入力します（実際のホストと `wss://` に置き換えてください）：

```text
wss://あなたの公開アドレス/ws
```

- サーバーは `/status`（HTTP状態チェック）と `/ws`（WebSocket）の2つのエンドポイントを公開します。
- ローカルの静的サーバー（8080番ポート）にこの2つのルートはないため、ゲームサーバーと誤認されることはありません。
- 公開デプロイの推奨手順：VPS + リバースプロキシ（Caddy/nginx + TLS）→ `wss`。開発中はFRP／SakuraFrpの内網トンネルが便利です。
- 自動再接続（指数バックオフ、最大5回）に対応。ローカルでの巻き戻しを通知し、復旧後は自動で再接続します。

## アーキテクチャ

```
index.html
├─ src/three-loader.js   Three.js ローカライズ優先、複数のCDNフォールバック
├─ src/main.js           アプリ組み立て、マルチプレイメッセージ、リソース保護、UIイベント
├─ src/world.js          全ブロック世界とクオッドツリーLODのスケジューリング、予算管理
├─ src/mesh-worker.js    メッシュ構築Worker（ハードウェアに応じて1–4スレッド）
├─ shared/               Workerと共有される純粋関数
│  ├─ constants.js       ブロックID、ワールドパラメータ
│  ├─ worldgen.js        プロシージャル地形生成
│  ├─ lod.js             クオッドツリーLODの層と帯域の分割
│  └─ mesh-builders.js   ボクセル / マクロビジュアルメッシュ構築
├─ src/visuals.js        ライティングプリセット、空、動的解像度
├─ src/materials.js      プロシージャルテクスチャ、連続水面、LOD近景マスクシェーダー
├─ src/settings.js       ローカル設定の永続化
└─ vendor/               three.module.min.js（ローカル依存）
```

核となる考え方：`shared/` のモジュールはメインスレッドとWorkerの両方で使えます。WorkerがTypedArrayのメッシュ（転送可能）を返し、メインスレッドがレート制限をかけながら組み込みます。**新しいメッシュができるまでは古いメッシュを表示し、用意できたらアトミックに差し替える**ことで、ストリーミング中の断層やチラつきを防ぎます。

## セーブと設定

- シングルプレイセーブ：3スロット。シード・位置・時刻・体力・インベントリ・編集した全ブロックを保存（決定論的生成により、未編集の領域はいつでも再現できます）。
- 設定：視野距離・ライティング・名前・ゲームモード・感度などをブラウザの `localStorage` に自動保存し、次回起動時に適用します。
